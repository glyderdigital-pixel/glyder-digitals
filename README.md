# Glyder Digitals website

A responsive Next.js website for Glyder Digitals, ready to deploy on Vercel.

## Requirements
- Node.js 18.17 or later
- npm

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Deploy to Vercel
1. Push the complete contents of this folder to the root of your GitHub repository.
2. In Vercel choose **Add New → Project** and import the GitHub repository.
3. Keep the detected framework as **Next.js** and click **Deploy**.

## Important
- Update the canonical website URL in `app/layout.js`, `app/sitemap.js`, and `app/robots.js` after your final Vercel URL or custom domain is known.
- The site intentionally contains no fabricated client testimonials, results, or portfolio claims. Add only genuine work and approved client feedback.
