# Glider Digitals Website

A responsive Next.js 14 website for Glider Digitals.

## Run locally
1. Install Node.js 18.17 or later.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Deploy to Vercel
Import the GitHub repository into Vercel. Keep the framework preset as Next.js and the root directory as `./`.
